# BeautifyAI - High-Fidelity AI Face Enhancement 🎨✨

BeautifyAI is a professional-grade face beautification application powered by the **Official CodeFormer** transformer-based architecture. It provides high-fidelity facial restoration, skin smoothing, and blemish removal while preserving the natural identity of the subject.

![BeautifyAI Preview](https://via.placeholder.com/1200x600?text=BeautifyAI+Face+Enhancement+Preview)

## 🚀 Key Features
*   **AI Face Restoration**: Clears acne, wrinkles, and blemishes using state-of-the-art transformer models.
*   **Intensity Control**: Fine-tune the enhancement level from natural touch-ups to high-end studio skin.
*   **Interactive Workspace**: Upload, preview, and download your results instantly.
*   **One-Click Setup**: Comes with a pre-configured backend and frontend.

## 🛠️ Technology Stack
*   **Frontend**: HTML5, Vanilla CSS3 (Modern Glassmorphism Design), JavaScript (ES6+).
*   **Backend**: Node.js, Express.js.
*   **AI Engine**: Python 3.13, PyTorch, CodeFormer (Official Implementation).

## 📦 Installation & Setup

### 1. Prerequisites
*   [Node.js](https://nodejs.org/) (v16+)
*   [Python 3.10+](https://www.python.org/)

### 2. Backend Setup
Go to the `backend` directory and install dependencies:
```bash
cd backend
npm install
pip install -r requirements.txt
```

### 3. Run the Application
Start the backend server:
```bash
# Run the bat file
start_backend.bat
```
Then open `index.html` in your browser or run a simple local server:
```bash
python -m http.server 3000
```
